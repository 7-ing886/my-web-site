# my-web-site —— 我的爱好小站

一个介绍我个人爱好（唱歌、游泳、健身）的简单静态网站。

## 目录结构

```
web-lab-04/
├── index.html      # 首页：导航条 + 爱好介绍 + 本周训练计划（嵌套列表）
├── news.html       # 爱好动态：锚点目录 + 定义列表 + 图片链接
├── about.html      # 关于我（分支 add-features 中创建）
└── images/         # 图片目录（当前使用占位文件名）
    ├── swimming-small.png
    └── swimming-big.png
```

## 使用说明

用 VSCode 打开文件夹，右键 index.html → Open with Live Server 即可预览。
